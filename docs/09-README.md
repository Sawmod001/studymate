# N-ATLAS StudyMate

N-ATLAS StudyMate is a voice-first multilingual AI study assistant designed for Nigerian learners.

## Why it exists
The project explores how N-ATLAS can make educational AI more accessible through Nigerian languages and voice interaction.

## Core flow

```text
Speak
  ↓
N-ATLAS ASR
  ↓
Transcript
  ↓
N-ATLAS
  ↓
Educational explanation
  ↓
Practice
```

## Tech
- Next.js
- React
- Tailwind
- Supabase
- Zod
- N-ATLAS
- Vercel

## Setup

```bash
npm install
npm run dev
```

Configure environment variables according to `.env.example`.

## N-ATLAS
The project must use the official N-ATLAS integration mechanism supplied/approved by NCAIR/NAIC.

Do not replace N-ATLAS with another general-purpose model.
