# NAIC Submission Evidence Checklist

## 1. Working Artefact
- [ ] Public deployed URL.
- [ ] Core flow works.
- [ ] Voice interaction works.
- [ ] Text interaction works.
- [ ] No broken critical routes.
- [ ] Demo account/session instructions if required.

## 2. N-ATLAS Integration Evidence
- [ ] Official N-ATLAS model/service identified.
- [ ] Integration code visible.
- [ ] Configuration documented.
- [ ] Secrets removed from screenshots/code.
- [ ] Request/response example captured.
- [ ] Voice ASR path demonstrated.
- [ ] LLM path demonstrated.

## 3. Real-World Validation
- [ ] 50+ real interactions.
- [ ] Anonymized dataset.
- [ ] Feedback collected.
- [ ] Results summarized.
- [ ] Problems discovered documented.
- [ ] Product improvements documented.

## 4. Technical Documentation
- [ ] README.
- [ ] PRD.
- [ ] TDD.
- [ ] AI architecture.
- [ ] N-ATLAS integration.
- [ ] API specification.
- [ ] Database schema.
- [ ] Deployment instructions.

## 5. Video
- [ ] 3–5 minutes.
- [ ] Problem.
- [ ] Working product.
- [ ] Voice demo.
- [ ] N-ATLAS integration.
- [ ] Validation.
- [ ] Impact.
- [ ] Clear audio.
- [ ] No private keys visible.

## 6. Team
- [ ] Team members.
- [ ] Roles.
- [ ] Short bios.
- [ ] Technical responsibility.
- [ ] Contact details required by application only.

## 7. Endorsement / Registration
Choose the applicable NAIC track and prepare its required evidence.

For Academic & Research:
- [ ] University/research institution eligibility.
- [ ] Team composition.
- [ ] Faculty supervisor.
- [ ] HOD/equivalent endorsement.

For Innovation & Enterprise:
- [ ] Individual eligibility or CAC registration as applicable.
- [ ] Team details if applicable.

## Final Compliance Check
- [ ] Only one NAIC problem statement selected.
- [ ] No unsupported claims.
- [ ] N-ATLAS is genuinely used.
- [ ] Validation is real.
- [ ] All application materials are in English.
- [ ] Submission completed before the official deadline.
