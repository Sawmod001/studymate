# NAIC Problem Statement and Track Decision

## Recommended Problem Statement

### Voice-First Access

StudyMate is designed specifically around voice-first educational access.

Why:
- Education/learning is explicitly relevant to this problem statement.
- Voice creates a meaningful Nigerian-language use case.
- N-ATLAS ASR is directly relevant.
- The product can demonstrate an end-to-end interaction instead of merely showing a chatbot.

## Important Trade-Off

Voice-First requires 50 documented real user interactions.

Therefore, do not select this track unless the team can realistically complete the validation.

## Why Not Sectoral Fine-Tuning for This MVP?

Sectoral Fine-Tuning requires actual fine-tuning of N-ATLAS and a 500+ example benchmark against the base model.

A normal education chatbot using the base N-ATLAS model is not sufficient evidence for that problem statement.

## Developer Infrastructure

This is a fallback direction only if the product becomes an N-ATLAS developer tool such as:
- SDK
- playground
- integration starter
- testing/evaluation tool
- documentation system

It is not the best description of StudyMate.

## Track

Choose the NAIC track based on the team's actual eligibility and evidence.

Do not claim Academic & Research eligibility without the required institutional endorsement.

Do not claim Innovation & Enterprise registration evidence unless it exists.

## Final Decision Rule

Before submission:
1. Confirm eligibility.
2. Confirm selected problem statement.
3. Confirm required evidence.
4. Build only what can be demonstrated.
5. Submit only claims supported by evidence.
