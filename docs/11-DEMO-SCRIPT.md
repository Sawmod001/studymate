# 3–5 Minute NAIC Demo Script

## 0:00–0:25 — Problem
"Many learners can understand difficult concepts better when they can ask questions naturally, including through familiar Nigerian languages. StudyMate uses N-ATLAS to make that interaction voice-first and multilingual."

## 0:25–0:45 — Product
Show landing page.

Say:
"StudyMate lets a learner select a language and academic level, ask a question by voice, and receive an educational explanation."

## 0:45–1:30 — Voice Interaction
Select Yoruba/Hausa/Igbo/Nigerian English.

Record a realistic academic question.

Show:
- Recording.
- Processing.
- Transcript.

Explicitly point out that the speech path uses the N-ATLAS ASR integration.

## 1:30–2:20 — N-ATLAS Answer
Show generated explanation.

Highlight:
- Explanation.
- Key points.
- Example.
- Common mistake.
- Practice question.

Say:
"The response is generated through our N-ATLAS integration rather than another general-purpose LLM."

## 2:20–3:00 — Learning Interaction
Click:
- Explain simpler.
- Step-by-step.
- Practice.

Show quiz and feedback.

## 3:00–3:30 — Validation
Show anonymized validation dashboard/table.

Mention only actual numbers.

Example wording:
"We tested the system with [ACTUAL NUMBER] real interactions across [ACTUAL LANGUAGES]. The main issue we found was [ACTUAL ISSUE], so we improved [ACTUAL CHANGE]."

## 3:30–4:00 — Technical Architecture
Show simple diagram:
Browser -> StudyMate API -> N-ATLAS ASR -> N-ATLAS -> Database.

## 4:00–4:30 — Impact
"StudyMate demonstrates a practical path for using Nigerian language AI in education, especially for learners who may find voice and familiar languages easier than conventional English-only interfaces."

End with:
"StudyMate is not a concept. It is a working N-ATLAS-integrated prototype validated with real users."
